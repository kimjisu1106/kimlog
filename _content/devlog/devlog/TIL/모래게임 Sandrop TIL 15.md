## Flutter — 표준 컴포넌트

### 흩어진 UI는 "무엇을"만 받는 하나의 컴포넌트로 묶는다

튜토리얼이 세 종류였는데(레벨1 조작·기믹 인트로·아이템 지급) 형태가 제각각이었다. 보드 튜토리얼은 게임판만 어두워지고, 아이템 튜토리얼은 아이템 바 전체가 밝아졌다. 하이라이트도 dim도 배너 위치도 코드가 다 따로였다.

공통점을 뽑으니 결국 셋 다 "화면을 어둡게 덮고 + 대상만 뚫어 강조 + 배너를 얹는다"였다. 그래서 그것만 하는 컴포넌트 하나로 묶고, 상황별로 "무엇을 강조할지(뚫을 사각형들)와 문구"만 넘기게 했다.

```dart
_TutorialOverlay(
  holes: [...],       // 밝게 뚫을 대상 (바스켓·아이템 버튼)
  bannerArea: rect,   // 배너 위치
  bannerText: '...',
);
```

이렇게 하니 오늘 열쇠·자물쇠 튜토리얼을 추가할 때 분기 하나 — "잠긴 바스켓 + 열쇠 바스켓을 강조" — 만 적으면 끝이었다. 형태(dim·글로우 링·터치 닫기)는 자동으로 딸려왔다.

배운 것 하나 더 — 셋을 하나로 합치려면 대상이 서로 다른 영역(게임판 안 vs 아이템 바)에 있어서 좌표 기준을 화면 하나로 통일해야 했다. 각자 자기 영역 좌표로 그리던 걸 화면 전체 기준으로 올린 뒤에야 한 컴포넌트로 묶였다.

---

### 화면 아무 곳이나 터치하면 닫히되, 게임 조작은 안 막는다

안내 배너를 X로만 닫게 두니 손이 갔다. "화면을 터치하면 닫히게" 하고 싶은데, 그 터치가 게임 조작(바스켓 탭)까지 삼키면 안 됐다.

`Listener`의 `onPointerDown`을 `translucent`로 걸면 터치가 내려온 걸 엿보기만 하고 소비하지 않는다. 그래서 아래 위젯(게임)은 그대로 탭이 되고, 나는 그 순간 배너만 닫는다.

```dart
Listener(
  behavior: HitTestBehavior.translucent,
  onPointerDown: (_) {
    if (_banner != null) setState(() => _banner = null); // 닫기만
  },
  child: gameStack, // 게임 제스처는 그대로 동작
)
```

"터치를 처리한다"와 "터치를 소비한다"는 다르다 — 엿보기만 하면 둘 다 만족한다.

## Python — 도구화

### 로컬 소스가 떨어지면 받아서 채운다

도안(이모지)을 계속 솎아내다 보니 500레벨에 모자랐다. 로컬 이모지가 이미 다 등록돼 있어 "더는 못 늘린다"고 생각했는데, 세어 보니 단일 코드포인트 이모지 중 미보유분이 아직 있었다.

Noto 이모지 저장소의 파일 목록을 git-tree API로 받아 보유분과 비교하고, 없는 것만 내려받아 다시 양자화했다. 표준 라이브러리(`urllib`)만으로 됐다.

```python
tree = json.load(urlopen(API))          # 저장소 파일 목록
new = [cp for cp in tree if cp not in have]  # 미보유분만
for cp in new: download(cp)             # 받아서 sources/에
```

핵심 안전장치 — 재양자화가 결정적이라 기존 도안은 한 글자도 안 바뀌고 새 것만 추가된다는 걸 커밋본과 diff로 확인했다(공통 559 불변, +164 신규). 안 그러면 이미 만든 레벨의 도안이 통째로 흔들린다.

### 규칙 상수를 옮기면 테스트도 같이 옮긴다

기믹 데뷔 간격을 균일하게 바꾸려고 데뷔 레벨 상수를 옮겼다(열쇠 251 → 351). 밀도 램프 경계는 상수를 참조해 자동으로 따라왔는데, 테스트가 깨졌다.

원인은 검증 fixture가 옛 열쇠 레벨(251·262·283)에 열쇠가 있는지 보는데, 열쇠가 351로 이사 가서 그 레벨엔 이제 없다는 것. 상수만 옮기고 그 상수를 전제로 짠 테스트를 안 옮긴 탓이었다.

```python
LEVELS = (351, 359, 388)  # 옛 (251, 262, 283) → 데뷔 이동 따라 갱신
```

"레벨 몇 번을 검사한다"처럼 상수에 묶인 테스트는, 상수를 옮기면 반드시 같이 옮겨야 한다.

## 게임 로직

### 아무것도 안 했으면 되돌려준다

레벨 진입에 하트를 1개 쓰는데, 잘못 들어가 아무 수도 안 두고 나가면 손해다. 그래서 "이 판에서 수를 한 번이라도 뒀나"를 플래그로 두고, 안 뒀고 이기지도 않았으면 나갈 때 하트를 돌려준다.

```dart
if (!_anyMove && status != won) meta.addHeart(); // 무이동 퇴장 환불
```

데드락·기권은 이미 수를 뒀으니(`_anyMove` true) 환불되지 않는다 — 되돌려주는 건 "실수로 들어옴"이지 "해보고 포기함"이 아니다.
