파티클 "폭"과 "높이" 슬라이더를 실제로 돌려보며 고칠 때 나온 것들.

---

## 파티클 폭

### 사인 흔들림 + 상승 = 나선(헬릭스)

폭(좌우 퍼짐)을 처음엔 "좌우 사인 진동"의 진폭으로 냈다. `x = 중심 + 진폭·sin(위상)`. 그런데 진폭을 키우니 파티클이 올라가면서 좌우로 크게 흔들려 나선처럼 돌았다. 사인으로 좌우를 오가는 것에 수직 상승이 겹치면 궤적이 나선(헬릭스)이 되기 때문이다. 폭이 작을 땐 안 보이다가 크게 하면 드러난다.

- 교훈: "넓게 퍼짐"을 좌우 진동으로 내면 안 된다. 스폰 위치를 좌우로 흩뿌리고(시작점을 넓게) + 필요하면 가로 속도에 배율을 주는 쪽이 맞다. 흩뿌림·속도는 나선을 안 만든다.

### 폭을 위치로 낼까 속도로 낼까 — 모션마다 다르다

폭을 "스폰 위치 흩뿌림"으로만 냈더니 방사형 개화(burst) 에선 폭을 최대로 해도 좁게 갇혔다. burst는 자기 방사 속도(`vx`)로 크게 퍼지는데, ±작은 위치 흩뿌림이 그 큰 속도에 묻혀 안 보였던 것이다.

그래서 폭이 가로 속도(`vx`)에도 배율로 먹게 했더니 burst는 반응했지만, 이번엔 조금만 올려도 과하게 퍼졌다(burst의 `vx`가 원래 커서 배율이 증폭됨). 반대로 bloom은 `vx`가 거의 없어 속도 배율이 약하게 먹는다.

- 교훈: 같은 "폭"이라도 모션의 퍼짐 메커니즘(위치 vs 속도)이 달라, 위치 흩뿌림 + 속도 배율을 함께 쓰되 배율 세기를 완만히 잡아야 한 슬라이더가 여러 모션에서 무난히 먹는다.

## 파티클 높이

### 항력이 있으면 "도달 높이"에 상한이 생긴다

높이를 "그 높이에 도달하면 소멸"로 만들려 했는데, bloom이 높이를 최대로 해도 화면 위까지 못 올라갔다. 원인은 항력(drag). 항력 하에서 속도는 `v ≈ v0·e^(−drag·t)`로 줄고, 이동 거리는 `v0/drag`(점근선)에서 멈춘다. 즉 아무리 오래 살려도 `v0/drag` 이상은 못 올라간다. bloom은 이 상한이 낮아 위까지 못 갔다.

- 교훈: "수명을 늘리면 더 높이 간다"는 항력이 없을 때만 성립. 높이 목표를 끝까지 채우려면 상승 구간의 항력·중력을 없애 등속으로 올려야 한다(좌우 흔들림은 남겨 느낌 유지).

### "도달 = 소멸" 수명 모델 — 속도와 높이를 분리

높이를 속도와 떼어내려면, 높이는 "어디까지", 속도는 "얼마나 빨리"로 나눈다. 등속 상승에서 목표 높이에 닿을 때 소멸시키려면 수명을 이렇게 잡는다.

```ts
// 높이(목표) ÷ 상승속도 = 그 높이에 닿는 시간 = 수명
if (rising) lifeSec = target / (-vy);
```

이러면 속도를 올려도 높이는 그대로(더 빨리 도달·더 빨리 소멸), 속도를 낮추면 천천히 오래 올라 같은 높이에 닿는다. 나선(spiral)이 원래 이 방식이라, 나머지 상승 모션도 같은 원리로 통일했다.

### 분수 apex 캡 — 과속해도 화면 밖으로 안 튀게

분수는 중력으로 포물선을 그린다. 최고점 `apex = v² / (2g)`. 속도를 올리면 apex가 커져 화면 밖으로 튀었다. 목표 높이를 넘지 않게 하려면 발사 속도를 캡한다.

```ts
const vMax = Math.sqrt(2 * gravity * target); // 이 속도면 apex = target
if (-vy > vMax) vy = -vMax;
```

수명·중력 아치는 그대로 두고 발사 속도만 캡하니, 과속해도 목표 높이에서 자연히 꺾여 내려온다.

### 한 파라미터를 모션 성격에 맞게 다르게 해석

결국 "높이"라는 한 슬라이더를 모션마다 다르게 적용했다 — 상승 플룸(bloom·흐트러짐)은 등속으로 목표까지 도달=소멸, 분수는 apex 캡(아치 유지), 방사형·불꽃·유영은 자기 수명 유지(높이 개념이 잘 안 맞음). 하나의 컨트롤이라도 모션의 물리 성격이 다르면 분기해서 각자에 맞게 해석하는 게 낫다.

## 요약

- "넓게 퍼짐"을 좌우 사인 진동으로 내면 상승과 겹쳐 나선이 됨 → 위치 흩뿌림 + 가로 속도 배율로
- 폭은 모션마다 퍼짐 방식(위치 vs 속도)이 달라 둘을 섞고 배율을 완만히
- 항력이 있으면 도달 높이에 상한(`v0/drag`) → 높이 목표를 채우려면 상승 구간 항력 제거(등속)
- 높이·속도 분리 = `lifeSec = 목표 / 상승속도`(빠르면 짧게·느리면 길게, 그 높이서 소멸)
- 분수는 `√(2g·목표)`로 발사 속도 캡 → 과속해도 apex가 목표를 안 넘음
- 한 파라미터라도 모션 성격이 다르면 분기해 다르게 해석(등속 도달 / apex 캡 / 자연 수명)
