PDF로 넣은 도면만 선이 굵게 뭉개진다는 제보에서 시작했다. 원인은 라이브러리가 아니라 "얼마나 크게 구울지"를 정하는 우리 계산식이었다.

---

## 벡터를 그림으로 굽기

### 목표 해상도를 "긴 변 N px"로 잡으면 큰 원본일수록 불리해진다

pdf.js로 페이지를 캔버스에 그리려면 배율을 정해야 한다. 예전 코드는 이랬다.

```js
const scale = Math.min(3, Math.max(1.5, 2500 / Math.max(v1.width, v1.height)));
```

작은 페이지는 3배까지 키우고, 큰 페이지는 2500px에 맞춰 줄이되 최소 1.5배는 보장한다는 뜻이다. 의도는 "너무 커지지 않게"였는데, 결과는 원본이 클수록 최소값에 눌러앉는 것이었다.

A1 도면(2384pt)이면 배율이 1.5로 깔려 3576px, 약 107dpi다. 0.1mm 선은 0.4픽셀이라 점 하나도 못 채우고 흐릿한 띠가 된다. 같은 도면을 이미지로 넣으면 얇게 나오던 건, 그쪽은 내보낼 때 정해진 해상도(대개 300dpi)를 그대로 들고 오기 때문이다.

고친 식은 목표를 크게 잡고, 대신 총 픽셀 수로 상한을 건다.

```js
let scale = Math.min(6, Math.max(1, TARGET_LONG_PX / Math.max(v1.width, v1.height)));
const px = v1.width * scale * (v1.height * scale);
if (px > MAX_PIXELS) scale *= Math.sqrt(MAX_PIXELS / px);   // 면적 기준이라 제곱근
```

상한을 긴 변이 아니라 면적으로 걸어야 가로로 긴 도면과 세로로 긴 도면이 같은 메모리를 쓴다. 배율은 길이에 곱해지므로 면적 비율의 제곱근을 곱한다.

---

### 크기 결정은 픽셀이 아니라 dpi로 환산해 판단한다

"6000px면 충분한가"는 답할 수 없는 질문이다. 종이 크기를 알아야 의미가 생긴다.

```text
A1 긴 변 = 841mm ≈ 33.1인치
6000px / 33.1 ≈ 181dpi
```

선 굵기도 같은 식으로 본다. 0.1mm 선이 1픽셀이 되려면 254dpi가 필요하다. 인쇄물이 300dpi를 기준 삼는 이유가 여기 있다.

목표를 정할 때는 "몇 픽셀"이 아니라 "이 종이에서 몇 dpi이고, 가장 얇은 선이 몇 픽셀인가"를 먼저 계산하는 편이 빠르다.

---

### 해상도를 올리면 저장 파일이 같이 무거워진다

이 도구는 구운 그림을 문자열로 바꿔 프로젝트 파일 안에 그대로 담는다. 자기완결 파일이라는 장점의 대가로, 해상도를 두 배로 올리면 파일도 그만큼 무거워진다.

화질은 올릴수록 좋지만 파일 크기와 여는 시간은 반대로 간다. 그래서 상수 두 개(목표 긴 변, 총 픽셀 상한)만 만지면 조절되게 두고, 실제 도면으로 균형을 정하기로 했다. 답이 하나로 정해지지 않는 값은 코드 여기저기 흩지 말고 손잡이 하나로 모아두는 게 낫다.

## 사이트 아이콘

### 파비콘이 없으면 브라우저는 HTML을 아이콘으로 받는다

탭 아이콘이 기본 모양이라 확인해 봤더니, 파일이 없는데도 요청은 성공하고 있었다.

```text
GET /favicon.ico  →  200  text/html
```

정적 호스팅이 없는 주소를 홈 페이지로 돌려주는 설정이라, 브라우저는 404가 아니라 HTML 문서를 받는다. 그림이 아니니 조용히 기본 아이콘을 쓴다. 콘솔에 오류도 안 뜬다.

파일이 없는 것과 파일이 잘못된 것이 겉으로 같아 보이는 경우다. 응답 코드만 보지 말고 콘텐츠 타입까지 확인해야 알 수 있다.

---

### 아이폰 홈 화면 아이콘은 투명을 검게 채운다

파비콘은 모서리를 둥글게 깎고 바깥을 투명하게 두는 게 자연스럽지만, iOS 홈 화면 아이콘(`apple-touch-icon`)에 같은 그림을 쓰면 투명한 부분이 검게 칠해진다. iOS가 알아서 둥글게 깎아 주기 때문에, 우리는 사각형 불투명으로 내야 한다.

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/assets/apple-touch-icon.png">
```

같은 마크라도 쓰이는 자리에 따라 만드는 방식이 다르다 — 파비콘은 투명 + 둥근 모서리, 터치 아이콘은 불투명 사각형.
