## 오늘 한 일

- 블로그
	- 게시글 본문 이미지 위아래 여백을 16px에서 28px로 넓힘
	- permalink 기반으로 전 게시글 URL을 랜덤 8자(`/xxxxxxxx/`)로 이관 — 616편 permalink를 랜덤 8자로 바꾸고, `public/_redirects`에 옛 URL→새 URL 301을 616줄 추가(한글·공백·em-dash·괄호는 percent-encode)
	- 파일럿(2편)으로 리다이렉트 인코딩이 라이브에서 실제 301되는지 먼저 검증한 뒤 나머지 614편을 배치로 이관
	- MCP 실험 랩 1에 실험 단계(0~6)별 결과 스크린샷 7장을 넣음(코드블록 사다리를 단계+사진 형태로 재구성, PNG→WebP 변환)
- 오픈데이 Openday
	- 백로그의 「캐릭터 그림」 항목을 닫았다. 그림이 들어갈 자리가 둘이었는데 같은 날 둘 다 정리됐던 걸 안 닫고 있었다
	- 그 낡은 문장이 이미 게시한 글의 「다음에 할 일」까지 따라가 있어서 게시글도 고쳤다

## 어려웠던 점

- 블로그
	- 이미지 넣기를 편하게 하려고 브라우저 글쓰기 도구(Sveltia CMS)를 로컬로 붙여 봤는데, 정작 필요한 "기존 글에 사진 추가"에서 저장하면 마크다운이 재작성돼 코드블록·포맷이 깨졌다 — 새 글엔 되지만 Obsidian으로 쓴 기존 글 편집엔 안 맞아 접었다
	- 전 URL을 바꾸면 옛 링크·색인·AdSense가 죽어서, 리다이렉트를 반드시 같이 넣어야 했고 한글·공백 URL 인코딩이 맞는지 파일럿 배포로 확인하고서야 전체를 돌릴 수 있었다
- 오픈데이 Openday
	- 「셔터 그림은 받았고 다른 자리에 쓸 것이 남았다」고 적혀 있었는데, 어느 자리냐고 물으니 답이 없었다. 항목을 안 닫으면 없는 할 일이 글까지 실려 나간다

## 배운 점

- 블로그 TIL 3편으로 정리
	- permalink로 게시글 URL을 파일명과 분리하기 — URL 출처를 frontmatter 필드로 옮기고 폴백을 두면 전 사이트 URL을 재편해도 옛 URL이 안 깨진다
	- 정적 사이트 전체 URL을 리다이렉트와 함께 이관하기 — Cloudflare `_redirects`는 공백이 구분자라 경로를 encodeURI, 배포로만 검증되고 엣지 캐시는 우회로 301 확인
	- Git 기반 CMS를 블로그에 붙여보고 접기까지 — 마크다운 CMS는 저장 시 본문을 재작성해 외부 작성 글을 손상시킨다(새 글엔 되지만 기존 글 편집엔 부적합)
