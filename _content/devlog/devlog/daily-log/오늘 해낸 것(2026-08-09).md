## 오늘 한 일

- 소리꽃 KeyBloom
	- 첫 방문자를 위한 5단계 가이드 투어와 데모곡(쇼팽 녹턴) 자동 로드를 만듦(펜으로 큐 놓는 법까지 짚어줌)
	- 샘플 피아노에 룸 리버브와 룸 사이즈 슬라이더를 넣고, 스타카토(짧은 음) 소리를 다듬음
	- 새 프로젝트·다른 이름으로 저장과 단축키(Ctrl+N·O·S·Shift+S)를 추가, 저장 안 한 변경이 있으면 물어보게 함
	- 영상 내보낼 때 리버브 여운을 끝까지 살리는 옵션과, 첫 노트가 잘리지 않게 앞에 짧은 무음을 넣음
	- 프리뷰가 오디오 길이까지 재생되게 하고, 프리뷰에서 첫 노트가 잘리던 것도 고침
	- 죽은 코드 삭제와 중복 정리, 반복 UI를 헬퍼로 묶는 정리 작업, 영어 화면에서 생기던 가로 스크롤 제거
- LOGSTONE Shop
	- KeyBloom을 파는 스토어를 열었다 — 소개·안내 페이지를 Astro로 만들어 logstoneshop.pages.dev에 배포. 결제는 Creem이 맡아 페이지 자체는 소개 위주
	- Claude design으로 만든 상품 소개 이미지 핸드오프의 룩을 제품 페이지에 그대로 입힘 — 커버·라이브 무대·모션 타일은 정지 이미지가 아니라 실제로 움직이는 파티클 캔버스
	- 소리꽃 KeyBloom 유튜브 재생목록을 영상 카드 캐러셀로 넣음(새 영상은 배포 때 자동 반영)
	- 영어 기본 + 한국어 전환의 이중 언어 구성

## 어려웠던 점

- 소리꽃 KeyBloom
	- 샘플 피아노 스타카토가 여전히 뭉툭해서, 엔벨로프만 손볼지 건반 뗄 때 소리(릴리스 샘플)까지 넣을지 방향을 정해야 했다
	- 라이브에서 실시간 투명 출력이 되는지 물었는데, 지금 웹 기반 구조로는 안 되고 크로마키나 미래 네이티브 앱으로 가야 한다는 걸 정리했다
	- 코드 정리를 어디까지 할지 — 내보내기 흐름을 바꾸는 위험한 리팩터는 실기로 확인한 뒤로 미루는 선을 정했다
- LOGSTONE Shop
	- 늘 걸리는 것 — 나는 "이렇게 해줘"로 방향을 정하고 확인·수정하며 만드는데, 코드를 직접 치진 않으니 "내가 만들었다"고 해도 되는지가 매번 애매하다. 무엇을 왜 만들지 정하고 결과를 판단하는 건 나라는 선에서 넘어갔다
	- 유튜브 재생목록 임베드가 한 곡만 재생돼서, 플레이어 하나를 고집할지 형태를 바꿀지 정해야 했다 — 영상별 카드 캐러셀로 바꾸는 쪽을 골랐다
