## 오늘 한 일

- 룸톤 Roomtone
	- 화면을 끄면 서너 곡 뒤 멈추던 백그라운드 재생 수정 — 전화·알림음·이어폰 빼기에도 반응
	- 가격을 월 $8로 정하고 판매 페이지·스토어 설명 반영
	- 판매 페이지 새 디자인(안내판) — 태블릿·폰 실제 화면, 요금과 가입 폼 나란히
	- Creem 월 구독 상품 실판매용 등록
	- 플레이 구독 상품, 결제 확인 서비스 계정, 구독 상태 알림, 내부 테스트 번들
	- 스토어 등록정보 영어판, 데이터 보안 설문 보강
	- 개인 계정 대신 심사용 계정 따로 만들기
	- 테스트 구독으로 전곡 재생과 만료 뒤 미리듣기 전환 확인
	- 앱→웹은 결제 없는 `/account` 화면으로, 외부 결제 프로그램 등록하기로
	- 로그스톤 샵에 가격 회신과 개인정보처리방침 보강 요청

- LOGSTONE Shop
	- 룸톤 제품 페이지 신설(한·영, 스토어 그래픽의 갈색·금색 테마)
	- 룸톤 가격 월 8달러로 표기, 세금은 결제할 때 나라별로 붙는다고 안내
	- 룸톤 첫 줄 소개에서 「시간표대로 알아서 바뀝니다」 제거
	- 룸톤 방침에 앱에서 만든 것·로그인 실패 기록·계정과 무관한 재생 통계 추가
	- 웹 구독 버튼을 결제 링크가 아니라 룸톤 판매 페이지로 연결

## 어려웠던 점

- 룸톤 Roomtone

	- 테스트 구독이 「구매를 확인하지 못했다」로 실패했다 — 서비스 계정에 앱 권한을 안 줬고, 준 뒤에도 반영이 늦었다
	- 앱에서 웹으로 가는 길이 플레이 결제 정책에 걸렸다

- LOGSTONE Shop
	- 결제 링크로 바로 보내면 돈은 나가는데 계정 번호가 안 실려 구독이 안 켜진다

## 배운 점

- 룸톤 Roomtone TIL 15로 정리
	- 화면을 끄면 멈추는 건 메트로놈 때 배운 포그라운드 서비스 문제였다
	- 라이선스 키 없이 Creem 결제가 룸톤 계정에 붙는 길
	- 플레이 서버에 물어볼 자격(서비스 계정 권한)을 따로 줘야 했다
	- 확인하지 않은 구매는 환불된다
	- 가격 하나를 정하니 나라마다 현지 가격이 붙었다
	- 테스트 구독은 공짜고 5분이면 한 달이 지난다
	- 앱에서 웹 결제로 가는 길에도 정식 창구(외부 결제 프로그램)가 있었다
