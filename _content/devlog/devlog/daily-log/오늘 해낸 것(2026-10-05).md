## 오늘 한 일

- 룸톤 Roomtone
	- 웹 결제 한 바퀴 — 결제부터 해지까지 끊긴 데 없이 확인
	- 판매 페이지에 로그인한 계정 이메일 표시
	- 어디서 결제했는지 표시 (웹 카드·스토어·무료 체험)
	- 해지 확인 메일 보내기 — 결제사가 안 보낸다
	- 「구독 관리 · 해지」 버튼 — 손님이 직접 해지할 수 있게
	- 약관의 해지 경로가 웹·스토어로 갈려 적힘 — 앱·판매 페이지 안내와 같은 기준
	- 판매 페이지 검색 노출은 차단하지 않기로 결정

- 모래게임 Sandrop
	- 도안 검토 결과 반영 — 샤워기와 회당을 빼고 그 두 판만 다시 뽑음
	- 폰에서 프레임 간격과 온도를 재서 발열과 끊김이 한 뿌리인 걸 확인
	- 주사율을 60Hz로 요청해 둘 다 잡음
	- 1.4.1 번들 생성

- 오픈데이 Openday
	- 셔터를 내린 뒤 뜨는 요약에서 카드를 걷고 셔터에 직접 그려 넣음
	- 한 일은 왼쪽, 강아지는 오른쪽으로 배치하고 강아지 뒤 어두운 판을 뺌
	- 요약 글씨를 어두운 페인트로 바꿔 대비를 2:1에서 5:1 위로 올림

- 로그스톤 샵 LogStone Shop
	- 룸톤 웹 구독 버튼을 다시 엶 — 결제 한 바퀴를 실제 버튼으로 돌려 보기 위해
	- 결제가 끝까지 통과해 버튼은 그대로 열어 둠
	- 약관의 웹 해지 경로를 판매 페이지 「구독 관리 · 해지」로 고침(메일 관리 링크도 함께)
	- Sandrop 1.4.1 문구를 받아 뒀고, 스토어 승격 확인 뒤에 싣기로 함

## 어려웠던 점

- 룸톤 Roomtone
	- 구독 관리 버튼이 실패했는데 우리가 준비한 안내 대신 플랫폼 오류 화면이 떴다
	- 결제사 API 키에 권한이 모자랐고, 만든 뒤에는 권한을 못 고쳐서 새로 만들어야 했다
	- 즉시 취소를 눌렀는데 계속 들려서 버그인 줄 알았다. 우리 방침대로 돈 것이었다

- 오픈데이 Openday
	- 카드를 걷었더니 왼쪽 글씨가 잘 안 보였다. 강아지는 같은 색인데 멀쩡히 보여서 색 문제로 보이지 않았다

- 로그스톤 샵 LogStone Shop
	- 시험하는 동안 결제가 실제로 열린다. 노출 차단을 걸지 않기로 해서, 그 몇 분은 검색으로 들어온 사람도 결제할 수 있는 상태였다

## 배운 점

- 룸톤 Roomtone TIL 23으로 정리
	- 한 번도 안 밟아 본 길은 밟아 봐야 무엇이 없는지 보인다
	- 되돌리기 어려운 버튼 앞에서는 지금 누구로 무엇에 하는지 보여 준다
	- 들어오는 길이 여럿이면 나가는 길도 여럿이다
	- 셀프로 들어오게 만들었으면 셀프로 나갈 수도 있어야 한다
	- 어긋나 보이면 버그를 찾기 전에 우리 규칙을 먼저 본다
	- 돈이 움직이는 일은 끝났다는 신호를 반드시 준다

- 모래게임 Sandrop TIL 37로 정리
	- 따로 보던 두 증상이 한 원인일 수 있다. 같이 재니 흐름이 보였다
	- 한 번 실패한 방향이라고 목표까지 버릴 건 아니다. 틀린 게 목표인지 방법인지 갈라 본다
	- 사양을 다 쓰는 것과 제품이 좋아지는 것은 다르다. 120Hz는 포기하기로 정했다
	- 비교 측정은 시작 조건이 같아야 한다

- 오픈데이 Openday
	- 선 그림은 형태로 읽히고 글씨는 획 사이 간격으로 읽힌다. 같은 자리에 같은 색으로 둬도 글씨만 묻힌다
	- 밝은 글씨를 살리려면 어두운 바탕을 깔아야 하는데, 그게 걷어내려던 카드다. 걷으려면 글씨 색을 뒤집는 쪽이 맞다
