## 오늘 한 일

- 소리꽃 KeyBloom
	- 출력 창 버튼을 관객 모니터에 바로 풀스크린으로 뜨게 함
	- 한번 정해진 파티클 배열을 다시 굴리는 버튼 추가(결정적은 유지)
	- 색 선택기에 RGB(0~255) 직접 입력칸 추가
	- PRO는 광고 없음, PRO 라이브 모드에선 하단 시퀀스를 크기 그대로 비움
	- 도움말에 큐 배치하는 방법 단계 추가
	- 결제·라이선스 백본 — 검증 시크릿을 앱이 아닌 클라우드에 숨기는 프록시 + 앱 실검증
	- 자동 업데이터 코드 + 서명 키쌍(새 버전이 나오면 앱이 알아서 받게)
	- 브랜드 색을 로즈핑크로 — 강조·삭제·파티클/건반 기본색까지
	- 투명 배경(알파) 영상 내보내기 완성 — PNG 시퀀스 + 단일 파일(Ut Video), 라이브 모드도
	- 안 쓰게 된 실시간 녹화 경로(죽은 코드)를 걷어냄
	- 로딩·저장 진행에 계속 도는 표시 + 지금 뭐 하는지 문구, PRO는 광고 자리를 시퀀서에 줌
	- 불러온 프로젝트를 저장할 때마다 대화상자가 뜨던 것 고침
	- 큐 순서를 바꿔도 시퀀서 첫 구간 번호가 안 따라오던 것 고침
	- PRO 잠금 배지를 한 곳에서 관리(컴포넌트화), 흰 배경 위 발광 색 유지, 크레딧을 버튼 토글로

## 어려웠던 점

- 소리꽃 KeyBloom
	- 파티클을 두 화면 맞추려고 결정적으로 만들어 놨는데, 그러면 배열이 마음에 안 들어도 못 바꾼다는 걸 뒤늦게 깨달아 "다시 굴리기"와 "재현" 둘 다 살릴 방법을 정해야 했다
	- 출력 창을 어느 모니터에 띄울지 자동으로 고르게 할지 정해야 했다
	- 라이선스 검증 시크릿을 앱에 넣으면 유출되니 어디에 숨길지 정해야 했다
	- 투명 영상을 편집툴이 읽게 하려면 어떤 코덱이어야 하는지, 유료 제품이라 코덱 라이선스까지 따져야 했다
	- 서명 키 비밀번호를 외워야 하는 줄 알고 부담스러웠는데, 안 외워도 되는지(관리자·빈 비번) 정해야 했다
	- 흰 배경 이미지 위에서 건반 발광이 하얗게 날아가는 걸 어디까지 자동으로 맞출지 정해야 했다
	- 큐 순서를 바꿨는데 시퀀서 첫 구간 번호만 안 바뀌어서, 왜 안 따라오는지 알 수 없었다

## 배운 점

- 소리꽃 KeyBloom TIL 36으로 정리
	- Tauri에서 붙은 모니터를 물어 주 모니터가 아닌 화면을 골라 그 자리에 창을 띄운다
	- 결정적 시드에 기준값을 하나 더 두면 "다시 굴리기"와 "저장 재현"을 둘 다 살릴 수 있다
	- 색은 hex·RGB·HSV가 같은 하나의 색을 가리키게 한쪽을 만지면 나머지를 다시 칠해 맞춘다
	- 검증 시크릿은 앱에 두지 말고 클라우드 프록시에 숨겨 앱은 그 서버에만 묻는다
	- 편집툴이 읽는 알파는 우리가 이미 뽑는 PNG 프레임을 ffmpeg가 다시 묶으면 스트리밍 없이 만들 수 있다
	- 발광은 가산 블렌드라 어두운 배경엔 맞지만 밝은 배경 위에선 하얗게 날아가, 배경 이미지가 있을 땐 일반 블렌드로 바꾼다
	- 하드코딩된 기본값(첫 구간 큐)은 상태로 추적해 재정렬·삭제·되돌리기·저장에 다 전파해야 한다
