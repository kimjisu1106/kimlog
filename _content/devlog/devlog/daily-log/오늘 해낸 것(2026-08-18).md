## 오늘 한 일

- 모래게임 Sandrop
	- 도안 검토 페이지에 레벨 번호 표시 — 어떤 그림이 몇 탄인지 보이게
	- 도안 출처별 필터와 표시 전환 추가(전체 / 레벨순 / 게임에 안 쓰인 것)
	- 예전에 뺐던 도안 8종을 다시 풀에 넣음
	- 승인 후 특정 레벨의 도안만 갈아끼우는 절차를 확인해 문서에 남김
- 여둘까 Office Layout
	- 구조 프리셋에 방 추가 — 벽 네 면을 각각 켜고 끄고, 두께를 지정하고, 가운데에 면적을 자동 표시
	- 면적 숫자는 가구에 가리지 않게 하고, 겹치면 끌어서 옮길 수 있게 함
	- 도형 위 이름 표시를 켜고 끄는 체크 추가
	- 텍스트 주석에 줄바꿈 입력 지원
	- 배치도 파일을 창에 끌어다 놓아 열 수 있게 함
	- 배치도 파일 아이콘 제작(여둘까 마크 기반)
	- 면적의 평 표기를 소수 둘째 자리까지
	- PDF로 넣은 도면은 선이 굵고 뭉개지는데 같은 도면을 이미지로 넣으면 얇게 나오는 걸 발견해 리포트
	- 팀 공유·동시편집을 유료화 방향(업무 도구화)으로 잡음
- LOGSTONE Shop
	- Sandrop 소개 페이지를 잠시 닫았다 — 심사가 길어져 "곧 공개"가 계속 걸려 있는 게 어색해서. 앱에 박힌 방침·약관 주소는 그대로 살려 두고 소개 페이지와 홈 카드만 내림
	- 메트로놈 제품 페이지에 버전별 업데이트 내역을 붙임 — 코드 저장소가 비공개라 내역 파일을 샵에 두고 빌드할 때 읽는 방식으로
	- 저녁에 올라온 두 버전을 이어붙여 다섯 개가 되면서 접기 버튼이 자동으로 생김
	- 공식 이메일 수신 방식이 바뀐 것을 문서에 갱신
- 메트로놈 Simple Metronome
	- 잠금화면과 블루투스·이어폰 버튼으로 재생·정지할 수 있게 함
	- 박마다 강세를 정할 수 있게 함 — 인디케이터를 누르면 강박(높은 음) → 일반 → 음소거로 바뀌고, 강박은 테두리 링·음소거는 흐리게 표시됨
	- 블루투스 이어폰은 소리가 조금 늦을 수 있다는 안내를 도움말에 넣음
	- 잠금화면 컨트롤과 강박 기능을 각각 출시함
- 룸톤 Roomtone
	- 곡 30개를 직접 귀로 검수·선별 — 음원 채우기가 파일럿 병목이라 우아·세련 기준으로 골라냄
- MiniMacro
	- 드래그와 스크롤 단계를 추가하고 녹화에서도 잡히게 함
	- 재생이 실패하면 몇 번 단계에서 왜 멈췄는지 표시하게 함 — 전에는 오류가 나도 "재생 완료"로 보였음
	- 편집 편의 — 복제, 여러 개 동시 선택, 단계를 지우지 않고 잠시 끄기, F5로 어디서든 재생
	- 단계 창을 마우스·키보드·대기 세 탭으로 정리하고 좌표 입력을 하나로 합침
	- 키 입력을 실제 키를 눌러서 채우게 함 — 키 이름을 외워 적던 유일한 자리였음
	- 창을 어떻게 바꿀지 시안을 두 방향으로 만들어 하나를 고르고 그대로 코드로 옮김
	- 새 창은 780×560 두 칸 구조로, 강조색은 메트로놈에 쓴 청록과 같은 값으로 맞춤
	- 재생·녹화 중 화면 위에 떠 있는 작은 막대를 만듦 — 진행 상황과 멈추는 법이 늘 보이게
	- 재생 버튼을 눌러 나눠 처음부터와 선택한 단계부터를 고르게 하고, 고른 쪽을 버튼 글자에 표시

## 어려웠던 점

- 모래게임 Sandrop
	- 도안 검토 페이지에 레벨 번호가 없어서, 마음에 안 드는 그림을 봐도 그게 몇 탄인지 알 수가 없었다
	- 이미 나간 500탄의 도안을 나중에 갈아끼울 수 있는지부터 확인해야 했다. 못 바꾸면 검토 자체가 소용없다
- 여둘까 Office Layout
	- 방 벽을 네 면 다 껐는데 위쪽에만 선이 남아, 벽이 안 지워진 줄 알았다
	- 그룹을 여러 번 돌리다 보니 도형 간격과 각도가 조금씩 풀렸다. 한 번에는 안 보이고 반복해야 드러나서 원인을 짚기 어려웠다
	- 되돌리기를 하면 반전해 둔 보조책상만 뒤집혀 돌아왔다. 출입문은 멀쩡해서 도형 종류 문제인 줄 알았는데, 반전을 걸어 둔 것만 해당된다는 걸 알아내는 데 시간이 걸렸다
	- 여러 줄 텍스트에 색을 입히면 줄바꿈이 사라졌다 — 색 바꾸기와 줄바꿈이 어디서 부딪히는지부터 가려야 했다
- LOGSTONE Shop
	- 페이지를 닫되 앱에 박힌 방침 주소는 살려야 해서, 어느 것이 계약이고 어느 것이 홍보물인지부터 갈라야 했다
- 메트로놈 Simple Metronome
	- 무선 이어폰으로 들으면 박이 조금 늦게 들리는데, 앱에서 잡을 수 있는 건지부터 확인해야 했다. 블루투스 구조상 어쩔 수 없는 지연이라 안내로만 두기로 했다
	- 강세를 어떻게 표시할지 정해야 했다 — 누를 때마다 강박·일반·음소거로 도는 3단계에, 강박은 테두리 링으로 표시하기로 골랐다
- MiniMacro
	- 창을 어떻게 고칠지 말로는 정해지지 않아, 방향이 다른 시안 두 개를 만들어 놓고 골랐다
	- 재생 중에 창을 남길지 내릴지 판단이 필요했다 — 진행 상황을 보여주려면 남겨야 하는데, 남기면 매크로가 그 창을 누를 수 있다
	- 조합키만으로 된 단축키는 눌러서 잡을 수 없다는 걸 확인하고, 고칠지 한계로 둘지 정해야 했다

## 배운 점

- 모래게임 Sandrop TIL 28로 정리
	- 화면에 없는 정보를 만들기 전에, 이미 파일에 있는지부터 본다
	- 목록을 고르는 자리는 하나로 모은다. 그리는 쪽과 개수 세는 쪽이 따로 고르면 어긋난다
	- 전체 생성만 생각하고 짠 코드는 부분 재생성에서 빠지는 로직이 있다
	- 판단을 되돌릴 때는 그 판단의 근거도 같이 지운다
- 여둘까 Office Layout TIL 7로 정리
	- 캔버스 라이브러리는 변형이 끝나면 도형 속성을 다시 계산해 덮어쓴다 — 반전은 세로 배율로 몰리고 회전이 보정되므로, 회전만 받아 적으면 화면과 기록이 어긋난다
	- 보여주기용 반올림과 저장값을 같은 자리에서 처리하면 되돌릴 때마다 오차가 쌓인다
	- 의미상 정확해야 하는 값은 매번 제자리로 되돌린다 — "거의 1"인 배율을 두면 반복하며 누적된다
	- 도형을 다시 만들면 맨 앞으로 나오므로 겹침 순서를 따로 챙긴다
	- 가려지면 안 되는 표시는 레이어를 나눈다
	- 투명하게 칠한 도형은 안 보여도 클릭은 잡힌다
	- 한 줄 입력칸은 값에서 줄바꿈을 지우므로, 여러 줄 값을 거기로 통과시키면 안 된다
	- 새 입력 요소를 넣을 때는 전역 단축키 가드를 함께 손본다
	- 파일 드롭은 드래그에 실린 것이 진짜 파일인지 먼저 가른다
	- 웹앱이 파일 연결을 가지려면 앱으로 설치돼야 한다
	- 윈도우 파일 아이콘은 확장자를 등록하면 앱 없이도 바뀐다
	- 아이콘은 크기별로 다른 그림을 담는 것이 원래 용도다
- LOGSTONE Shop
	- 로그스톤 샵 LogStone Shop TIL 4로 정리 예정(기술 포인트 선택 대기)
- 메트로놈 Simple Metronome TIL 8로 정리 예정(기술 포인트 선택 대기)
- MiniMacro TIL 2로 정리
	- 화면 테마를 갈아타면 그 테마가 미리 걸어둔 기본값부터 의심한다 — 지정하지 않은 값이 이미 들어 있어 배치를 망칠 수 있다
	- 위젯이 못 만드는 모양은 억지로 맞추기보다 직접 그리는 게 짧고 확실하다
	- 편의를 위해 기억하는 값은 눈에 보여야 안전하다 — 안 보이면 어제 고른 값으로 오늘 엉뚱한 데서 시작한다
	- 녹화 중 화면에 버튼을 두면 그 버튼을 누르는 것까지 기록된다
	- 검증 환경이 실제 실행과 다르면, 코드가 아니라 검증이 틀렸을 수 있다
- 사업·등록
	- 구글플레이 모바일 게임은 플랫폼 자체등급분류(IARC)로 처리돼 별도 심의 제출이 없다
