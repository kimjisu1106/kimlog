## 오늘 한 일

### CS2 Practice Host 제품 페이지 신설

- 샵에 여섯 번째 제품 페이지를 세웠다(`logstone.net/cs2host/`, 한·영). 홈 카드도 같이 열었다
- Claude한테 색은 앱 아이콘에서 뽑으라고 했다. 아이콘의 남색 바탕과 노란 조준선, 하늘색 테두리를 페이지 색으로 그대로 쓴다
	- 이 페이지만 어두운 테마다. 룸톤과 같은 방식으로, 공통 색 변수를 이 페이지에서만 덮는다
- 받기 버튼은 스토어가 아니라 GitHub 릴리스 직링이다. Windows 전용 무료 도구라 설치파일을 바로 받는다
	- 버전이 올라가도 주소가 안 바뀌도록 「최신 릴리스」를 가리킨다. 다만 릴리스마다 파일 이름이 같아야 링크가 안 깨진다
	- 옆에 「GitHub에서 소스 보기」와 「사용법 보기」 버튼을 뒀다
- 받기 절 아래에 고지 둘을 넣었다
	- 서명이 없어 Windows가 경고를 띄운다는 것. 「추가 정보」 → 「실행」으로 진행하면 된다고 적고, 소스가 공개라 직접 확인할 수 있다는 점을 같이 뒀다
	- 비공식 도구이고 Valve·Counter-Strike와 무관하다는 것
- 화면 셋은 내가 게임 PC에서 찍었다. 앱 본 화면, 서버가 열린 상태, 친구가 받는 안내 페이지다

### Sandrop 1.4.0 업데이트 내역

- 09-29 밤에 스토어 라이브가 1.4.0으로 바뀐 것을 확인하고 제품 페이지 업데이트 내역에 실었다. 09-29 로그를 쓴 뒤에 올라와서 이번 편에 적는다

### 방침은 한 쪽만

- 이 앱은 계정이 없고 수집하는 것도 없다. 설정은 쓰는 사람 PC에만 저장되고 서버 주소는 그 사람 클립보드로만 간다
- 그래서 처음에는 방침도 약관도 만들지 않기로 했다. 쓸 내용이 「수집하지 않는다」 한 줄뿐이라 페이지를 따로 둘 값이 없었다
- 그런데 친구가 받는 안내 페이지에 광고가 붙어 있었다. 스크린샷을 다듬다 보고 알았다
	- 그 페이지는 앱을 받은 적도 없는 사람이 링크를 눌러 들어오는 자리다. 「앱은 수집하지 않는다」로는 덮이지 않는다
- 그래서 방침 한 쪽만 만들었다(`logstone.net/cs2host/privacy/`). 앱이 보관하는 것과 광고 조항, 그리고 공통 조항이 들어간다
	- 광고 조항은 다른 제품이 쓰던 문장을 그대로 쓴다. 같은 성격의 문서가 두 군데서 따로 늙지 않게 하려는 것이다
- 약관은 만들지 않았다

## 막힌 부분

- 제품을 법무 목록에 넣으면 약관 페이지까지 자동으로 생긴다
	- 방침만 필요한데 목록에 넣는 순간 둘 다 생성된다. 제품마다 방침·약관을 쌍으로 두던 구조라서다
	- 해결: 이 제품만 목록에서 빼고 방침 주소를 따로 뒀다. 왜 뺐는지 코드 주석에 적어 두지 않으면 나중에 「빠졌네」 하고 다시 넣기 쉬워서 이유까지 같이 적었다

### 스크린샷에 접속 가능한 주소가 찍혀 있었다

받은 화면 넷 중 셋에 서버 주소와 참가 코드가 그대로 보였다. 안내 페이지 화면에는 광고 배너까지 들어 있었다.

주소를 아는 사람은 누구나 그 서버에 들어올 수 있다. 제품 페이지는 검색에 열려 있으니 그대로 올리면 사진 한 장으로 주소가 공개된다.

- 해결: 주소와 참가 코드는 흐리게 가리고, 광고 배너는 흐리게 두는 대신 잘라냈다. 흐린 광고는 자리만 차지하고 제품과 상관도 없다
- 남긴 것: 「주소를 아는 사람은 누구나 들어올 수 있다」는 앱 안내 문구는 가리지 않았다. 받는 사람이 알아야 할 주의라서다
