## 오늘 한 일

- 게임오버를 3단 모달로 — 이어하기 유도 → 하트 차감 경고 → 하트 없음
	- 이유: 한 번에 "실패했습니다"로 끝내면 되살릴 기회를 못 보고 나간다
- 200레벨을 다 깨면 "새로운 레벨을 기다리는 중" 노드가 뜨게
- 벨트에 몇 개 올라가 있는지 배지로 보여주고, 광고를 보면 한 개를 대기로 뺄 수 있게
- 게임 화면 정리
	- 뒤로가기를 없애고 우상단 톱니 → 다시하기 / 목록으로 / 계속
	- 아이템에서 이름·가격 글자를 빼고 아이콘만. 상태는 우하단 배지가 말하게
	- 그림 폭을 아래 바스켓 판 폭과 정확히 맞춤
- 아이템은 3개 묶음으로만 팔고 10% 할인
- 벨트를 2.5D로 — 띠를 밴드 높이의 60%만 그려 바스켓 윗부분이 띠 위로 나오게
	- 바스켓이 양끝 통로로 들어갔다 반대쪽에서 나오는 연출을 살림
	- 벨트가 비어 있어도 판이 시작되면 서서히 돌기 시작
- 캔버스를 다 채우면 보조선(크러스트)이 페이드아웃되며 사라지게
- 셔플이 기믹 바스켓(로프·미공개 물음표)은 건드리지 않게
- 난이도 곡선을 다시 세움 — 목표 클리어율을 레벨 번호의 연속 함수로
	- 이유: 41레벨부터 전부 같은 티어라 160레벨을 지나는 동안 난이도가 10%p밖에 안 내려갔다
- 보드 밀도 상향 — 바스켓 20.4 → 27.5개, 빈칸 19.3 → 13.4칸
- 열쇠 & 길막 기믹 (레벨 251 데뷔)
	- 길막은 잠긴 동안 벽과 같고, 열쇠 바스켓을 꺼내면 열려서 그 뒤 바스켓을 쓸 수 있게
- 한국 도안 10종을 직접 그려 넣음 — 태극·복주머니·기와집·까치·갓·청사초롱·방패연·장구·백자·무궁화
	- 이유: 이모지 코퍼스에 한국 소재가 거의 없다

## 막힌 부분

- 다음 레벨 버튼을 눌러도 전면 광고가 안 뜨던 것
	- 원인: 광고를 레벨 목록 화면이 다시 보일 때만 띄우게 해놨는데, 승리 모달에서 다음 레벨로 가면 목록을 거치지 않는다
	- 해결: 승리 모달에서 나가는 모든 경로에 광고를 붙이고 목록 쪽 호출은 제거
- 아이템 아이콘을 눌렀는데 구매 모달이 열리던 것
	- 원인: 우하단 배지의 터치 영역이 아이콘 우하단을 12.5px 덮고 있었고, 그 영역이 탭을 가로챘다
	- 해결: 카드 바깥에 배지 자리를 미리 비우고 배지를 카드 밖으로 옮김. 겹침 0
	- 남은 한계: 터치 영역을 카드 바깥으로 넓히는 방법은 안 통했다 — 부모 영역 밖은 탭이 전달되지 않는다
- 벨트 띠 높이를 낮췄더니 양끝 통로 폭·높이가 같이 줄어든 것
	- 원인: 통로 크기를 띠 높이 기준으로 계산하고 있었다
	- 해결: 통로는 밴드 높이 기준으로 분리. 폭만 고치고 높이를 놓쳐서 두 번에 걸쳐 고쳤다
- 벨트 무늬가 바스켓보다 빨라 따로 놀던 것
	- 원인: 무늬는 밴드 전체 폭만큼 흐르는데 바스켓은 양끝 여백을 뺀 만큼만 이동한다
	- 해결: 이동 거리를 하나로 공유. 정확히 20% 차이였다
- 난이도를 조이려 밴드만 좁혔더니 목표를 못 맞추던 것
	- 원인: 탐색 범위가 그대로라 도달할 수 없는 목표가 됐다
	- 해결: 벽·매장 깊이·아래쪽 편향의 탐색 범위를 레벨 번호에 따라 같이 넓힘
- 바스켓을 늘렸는데 밀도가 안 오르던 것
	- 원인: 밀도와 난이도가 같은 예산을 나눠 쓴다. 바스켓이 늘면 생성기가 목표 클리어율을 맞추려고 벽을 뺐다
	- 해결: 색당 바스켓 수를 보드 용량까지 못 박아 밀도를 하한으로 만들고, 난이도는 벽·깊이·편향으로만 맞추게
- 매그넷으로 열쇠를 빼면 길막이 안 열리던 것
	- 원인: 보드를 떠나는 경로가 올리기·매그넷 둘인데 길막 해제를 한쪽에만 넣었다
	- 해결: 떠날 때의 처리를 한 함수로 모아 두 경로가 반드시 지나게
- Noto Emoji 라이선스를 Apache 2.0으로 적어둔 것
	- 원인: 실제로 받아둔 LICENSE 파일은 SIL OFL 1.1이었다
	- 해결: 앱 설정의 오픈소스 라이선스 화면과 문서를 정정. 사용자에게 보이는 법적 고지라 출시 전에 잡아야 했다
