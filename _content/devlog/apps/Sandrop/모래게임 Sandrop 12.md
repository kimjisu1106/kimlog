## 오늘 한 일

- 500레벨 생성 완료 — 이모지를 더 받아 도안 풀을 595종까지 늘림
- 색이 3개인 도안을 없앰
	- 이유: 65레벨까지 해봤더니 색이 3개인 판은 무슨 그림인지 알아볼 수가 없었다
- 색이 4개여도 서로 비슷하면 똑같이 안 읽힌다는 걸 확인하고, 색끼리 최소 거리를 품질 기준으로 넣음
	- 기준을 못 지키는 도안은 그냥 버림. 1088종 중 566종만 통과
- 난이도 곡선을 3배로 압축 — 예전 200레벨 난이도가 이제 65레벨에
	- 이유: 65레벨까지 전부 시시했다
- 최고 어려움 티어를 새로 만들고, 난관을 100레벨마다 한 단계씩 열리게 함
	- 어려움 8레벨마다 / 매우 어려움 101레벨부터 / 최고 어려움 201레벨부터
- 보드에 바스켓이 최소 10개는 되게 함
- 한국 도안을 19종으로 늘림 — 호랑이·학·김밥·떡볶이·소주·청자·소나무·합죽선, 그리고 직접 그린 한복
	- 이유: 게임을 하다 익숙한 문화 소재를 만나면 반갑고, 반대로 특정 나라색이 짙은 소재가 자주 나오면 "개발자가 그 나라 사람이구나" 하게 된다. 한국 유저에게 그 반가움을 주고 싶어 한국 소재를 늘리고, 도안 풀은 한국·보편 소재 위주로 큐레이션했다 (초밥·라멘·오뎅처럼 한국에서도 일상인 건 남김)
- 하트 5개를 900코인에 사는 길을 둘 만듦 — 상점 카드, 그리고 하트가 0일 때 하트를 누르면 바로 구매
- 레벨 생성을 병렬로 돌려 500레벨이 80분에서 3분으로 줄어듦
- 도안 뷰어와 표본 미리보기 도구를 만듦

## 막힌 부분

- 색을 3개에서 늘렸더니 이번엔 비슷한 색끼리 섞여 나옴
	- 원인: 색을 합치는 기준을 느슨하게 했더니 색 수는 늘었지만 거의 같은 색이 안 합쳐졌다. 한 레벨에 청회색 셋이 들어가 있었다
	- 해결: 색 수와 색 구분을 따로 다뤘다. 색끼리 최소 거리를 못 지키는 도안은 버리고, 대신 이모지를 더 받아 개수를 채웠다
	- 남은 한계: 직접 그린 도안은 이 검사를 안 거쳐서 5종이 아직 걸린다
- 색을 억지로 벌려서 해결하려다 배경 대비가 깨짐
	- 원인: 전경끼리 밝기를 벌리면 그중 하나가 배경에 가까워진다
	- 해결: 되돌리고 "버리는" 쪽으로. 예전에도 같은 시도를 하고 폐기한 기록이 문서에 있었는데 못 보고 다시 밟았다
- 난이도를 조였는데 목표보다 훨씬 어렵게 나옴
	- 원인: 생성기가 난이도를 낮출 때 쓰는 손잡이가 하나뿐이었는데, 보드를 빽빽하게 만들려고 그걸 고정해버렸다
	- 해결: 밀도에 하한만 두고 조절 여지를 남김
- 레벨 하나에 바구니 칸이 6개로 나옴
	- 원인: 생성기가 배치를 못 찾으면 칸을 늘려서라도 풀리게 하고 있었다. 37개 레벨이 그랬다
	- 해결: 칸 수는 절대 안 건드리고 대신 바스켓을 굵게 뭉치게 함. 5칸은 규칙이라 레벨마다 다르면 안 된다
- 난이도 배지가 안 보임
	- 원인: 레벨 번호와 같은 줄에 뒀더니 폭이 좁을 때 배지가 0까지 눌렸다
	- 해결: 아랫줄로 분리
- 도안이 중복됐다는 경고가 뜨는데 실제 중복은 0
	- 원인: 시도한 것과 실제로 쓴 것을 구분 안 하고 세고 있었다
	- 해결: 채택된 것만 세게 함. 거짓 경고는 나중에 진짜 문제를 무시하게 만든다
- 도안 하나가 조용히 사라짐
	- 원인: 직접 그린 호랑이와 이모지 호랑이의 이름이 같았고, 중복 판정이 이름 기준이었다
	- 해결: 직접 그린 도안에 접두어를 붙임
