## 막힌 부분

### 살 것을 늘릴지 코인팩을 팔지 지금 자료로는 못 고른다

코인으로 살 수 있는 건 아이템(되돌리기 300·자석 700·섞기 1000), 하트 5개 900, 이어하기 900이다. 들어오는 쪽은 레벨 클리어, 일일 보상 50~200, 보상형 광고 50이다.

막힌 지점은 이 둘이 안 갈린다는 것이었다. 코인 기록이 아예 없어서 남아서 안 쓰는지 모자라서 못 쓰는지를 볼 방법이 없다.

- 해결: 코인 입출금에 잔액을 같이 실어 보내게 했다. 「얼마를 썼나」만으로는 안 갈리고 「쓸 때 얼마를 들고 있었나」가 있어야 갈린다
- 남은 한계: 다음 업데이트가 나가야 쌓이기 시작한다. 판단은 그 뒤다

### 지급 경로가 늘면 계측이 조용히 빠진다

코인을 넣고 빼는 곳이 여덟 군데였다. 나중에 지급 경로를 하나 더 만들면서 계측을 안 붙이면, 그 경로만 기록에서 빠진 채로 아무 경고 없이 돈다.

그래서 코인 함수가 「어디서 들어왔는지」와 「무엇에 썼는지」를 반드시 받게 했다. 안 넘기면 컴파일이 안 된다.

```dart
Future<void> addCoins(int n, {required String source}) async { ... }
Future<bool> spendCoins(int n, {required String item}) async { ... }
```

- 해결: 기존 호출부 여덟 곳과 테스트 셋을 전부 맞췄다. 테스트 707개 통과
- 남은 한계: 보내는 이름이 틀려도 컴파일은 통과한다. 이름 오타는 콘솔에서 봐야 안다
