## 오늘 한 일

- 칸 수 자동 감지를 고치고, 못 맞히면 포기하게 바꿈
  - 이유: 48px 칸 4×4 시트가 3×3으로 잘렸는데 아무 말도 없었다
- 색 거리·배경 거리·채움 하한·상한 네 값을 화면에 꺼냄
- 칸 둘레 빈 자리를 쳐내 그림 둘레 테두리를 없앰
- 카드의 그림을 눌러 자를 자리를 직접 맞추는 오버레이 추가
- 틀이 칸 밖으로 몇 px 넘어갈 수 있게 해서 좌우로 움직일 여유를 만듦

## 막힌 부분

- 설정 넷이 `Settings`에는 있는데 화면에 입력칸이 없었다
  - 원인: 화면이 꺼낸 것은 색·크기·시트 가로·세로·주인공 자리 다섯뿐이었다
  - 해결: 접힌 칸으로 넷을 꺼내고 변환 요청에 실어 보낸다. 풍경 시트가 기본값에서 15/16, 색 거리를 20으로 내리면 16/16이 된다
- 원본 칸 그림을 브라우저에 내주는 길이 새로 생겼다
  - 해결: `out` 안으로 경로를 제한하고 바깥 요청은 404로 막았다. 화면이 보내는 틀 값도 서버에서 한 번 더 자른다

### 결과 격자 크기를 원본 칸 크기로 쓰고 있었다

칸 수를 비워 두면 그림 크기를 보고 짐작하는데, 짐작에 쓸 값이 「크기」(결과 격자) 하나뿐이었다. 192는 64로도 나눠떨어지니 48px 칸 4×4 시트가 3×3으로 잘렸다. 둘 다 이름이 「크기」라 입력칸을 봐도 구별이 안 된다.

```python
def detect_grid(path: str, tile: int = 64) -> tuple[int, int]:
    w, h = Image.open(path).size
    if w % tile or h % tile:
        return 1, 1
    cols, rows = w // tile, h // tile
    return (cols, rows) if cols * rows > 1 else (1, 1)
```

- 해결: 「칸 크기」를 별도 입력으로 뺐다. 경계마다 완전히 빈 줄이 있는지 확인하고, 없으면 `(0, 0)`으로 포기해 쓰는 사람에게 넘긴다

### 자동 감지로 못 가르는 시트가 있다

경계의 투명도를 세는 방법을 두 가지로 재 봤는데 둘 다 틀렸다. 재 보니 이유가 나왔다.

```text
꽃 시트 256x256   x=31,32,63,64,95,96 → 불투명 0/256 (전부 비어 있음)
풍경 시트 192x192  전체 불투명 비율 63%
  x= 47  불투명 0/192     x= 48  불투명 96/192
  x= 95  불투명 0/192     x= 96  불투명 48/192
```

꽃 시트는 그림이 작고 여백이 넓어 2·4·8 어디서 잘라도 경계가 비어 있다. 풍경 시트는 칸이 꽉 차서 경계 자체가 없다.

- 해결: 맞힐 수 있는 경우만 답하고 나머지는 「몇 칸인지 짐작할 수 없다, 직접 넣어 달라」로 띄운다

### 자른 컷의 빈 자리가 배경색으로 칠해져 테두리가 됐다

컷은 48×48인데 그림이 차지하는 데는 `(0, 6)-(45, 45)`였다. 위 6px, 오른쪽·아래 3px이 투명이고 그 자리가 배경색이 되니 액자처럼 보인다. 쳐내는 방식을 셋으로 재 비교했다.

| 방식 | 변환 성공 | 테두리 |
| --- | --- | --- |
| 그대로 | 15/16 | 있음 |
| 내용에 딱 맞추고 늘림 | 14/16 | 없음 |
| 정사각으로 넓혀 자름 | 15/16 | 없음 |

- 해결: 정사각으로 넓혀 자른다. 딱 맞추면 가로로 긴 그림이 정사각 격자에서 세로로 늘어난다

### 쳐낸 결과만 남기면 되돌릴 수가 없다

자를 자리를 직접 맞추는 오버레이를 붙이려는데, 자동으로 쳐낸 그림만 저장돼 있어 쳐낸 바깥으로 틀을 옮길 수가 없었다.

- 해결: 자른 칸은 손대지 않고 저장하고, 쳐내기는 `(x, y, 한 변)` 셋으로만 들고 있게 바꿨다. 자동 쳐내기는 그 틀의 첫 값일 뿐이라 어디로든 옮길 수 있다

### 자동 틀이 칸과 거의 같아 끌어도 안 움직였다

틀이 45px인데 칸이 48px이라 좌우 여유가 3px뿐이었다.

- 해결: 틀을 칸 밖으로 `max(5, 한 변/8)`px까지 내보낸다. 범위가 3px에서 13px로 늘었다
- 남은 한계: 넘어간 자리는 빈 칸이라 배경색으로 칠해진다. 칸 밖 픽셀을 지어내거나 옆 칸을 끌어올 수는 없어서 여유를 만드는 방법이 이것뿐이다
