## 오늘 한 일

- UI/UX 개선안을 캔버스에 화면 세 장으로 받아 봤다. 데스크톱 전체 화면, 태블릿 재기 모드, 속성 패널 지금·제안 비교
	- 여섯 가지 다 넣기로 했다. 스냅 자석 아이콘만 선이 얇아 자석으로 안 읽혀서 굵게 하고 양 끝 극을 빨갛게 칠했다
- 순서를 정해 하나씩 넣었다 — 빈틈을 막는 것 먼저, 기존 동작이 바뀌는 것은 마지막
	- 재는 동안 도면 아래에 작업 띠를 띄웠다. 지금 무엇을 재는지, 다음에 할 일, [점 하나 되돌리기] [그만]
	- 평면도를 연 뒤 툴바 아랫줄에 시작 띠를 띄웠다. 평면도 열기 → 축척 맞추기 → 가구 놓기 중 지금 단계와 그리로 가는 버튼
	- 속성 패널을 이름·크기 / 모양 / 돌리기·뒤집기 / 겹침 순서로 묶고, 기호만 있던 버튼에 글자를 붙였다. 가로·세로 비율 고정 자물쇠와 실선/점선 두 칸도 넣었다
	- 툴바를 선택·거리·면적 / 그리기 / 보기 세 묶음으로 나눴다. 측정 드롭다운에 있던 거리·면적을 선택 옆으로 꺼냈고, 격자 간격 칸은 프로젝트 설정으로 옮겼다
	- 서랍 손잡이를 44×96으로 키우고 「가구」「속성」을 세로 글자로 적었다
	- 팔레트는 마우스도 누르면 화면 가운데에 놓이게 했다. 편집은 항목 끝 ⋯ 버튼으로 옮기고, 가구 찾기 칸과 최근 쓴 것도 넣었다
- 사용법 가이드를 바뀐 화면에 맞췄다. 거리·면적·팔레트·속성·격자 슬라이드를 한·영 둘 다 다시 쓰고 스크린샷을 다시 찍었다(인쇄 28쪽 그대로)
- 회귀 검사에 다섯을 넣었다 — 작업 띠, 시작 띠, 속성 패널 비율 고정, 팔레트 누르기·찾기·최근, 그리고 기존 탭 거름망 검사 하나를 옮겼다

## 막힌 부분

- 새로 넣은 작업 띠 검사가 첫 클릭을 놓쳤다
	- 원인: 바로 앞 검사가 쏜 손가락 탭 뒤 0.8초 안의 클릭이라, 탭 뒤에 따라오는 합성 클릭으로 보고 거름망이 버렸다
	- 해결: 검사 앞에 한 박자 쉬게 했다. 실제로는 손가락으로 탭한 뒤 0.8초 안에 마우스를 누를 일이 없다
- 회귀 검사가 한 번 원인 모르게 「찾는 요소가 없다」로 끊겼다
	- 그 뒤 세 번 연속 통과해 다시 나오지 않았다. 원인은 못 잡았다
- 새로 넣은 안내 두 줄이 반말(「놓인다」「맞춰진다」)이었다
	- 원인: 앱 안내는 대부분 존댓말(「클릭하세요」「조정할 수 있습니다」)인데 맞추지 않았다
	- 해결: 존댓말로 고치고 가이드를 다시 찍었다
- 측정 드롭다운을 없애면서 가이드 촬영 스크립트가 깨질 자리였다
	- 원인: 거리·면적 화면을 찍기 전에 그 드롭다운을 열도록 짜여 있었다
	- 해결: 드롭다운 열기를 걷고, 화면에서 짚는 동그라미를 거리 버튼·작업 띠·지우기 버튼으로 바꿨다. 동그라미 수와 설명 줄 수가 슬라이드마다 맞는지 대조했다

### 측정 드롭다운을 다시 꺼냈다

09-07에 거리·면적 재기를 「📐 측정 ▾」 드롭다운 안에 넣었었다. 그때 이유는 기호만으로는 두 재기 도구가 안 갈린다는 것이었다.

이번 툴바 묶음에서 그 둘을 선택 옆으로 꺼냈다. 버튼에 「거리」「면적」 글자를 늘 보이게 하니, 드롭다운을 한 번 더 열어야 할 이유가 없어졌다. 「측정 전부 지우기」는 같은 묶음 끝의 🧹 버튼이다.

- 해결: 드롭다운을 없애고 버튼 id는 그대로 둬 배선과 검사가 안 깨졌다
- 남은 한계: 태블릿(1056px)에서는 툴바가 아직 두 줄이다. 손가락 기기에서는 툴팁을 못 띄워서 버튼 글자를 일부러 남겨 둔 탓에 도움말 하나가 넘어간다
