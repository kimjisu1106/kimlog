## 오늘 한 일

- 구글 저장이 한 번도 올라가지 않던 것을 고쳤다
	- 원인: 플레이 게임즈 앱 ID 자리에 Firebase 프로젝트 번호가 들어가 있었다
	- 고친 판을 폰과 태블릿에 깔아 두 기기 진행이 같아지는 것을 봤다
- 처음 연결하는 기기의 지갑(코인·크리스탈·아이템·티켓)이 저장본과 다르면 어느 쪽으로 이을지 묻게 했다
	- 이유: 진행은 더 많이 깬 쪽으로 합치면 되지만, 지갑은 어느 쪽이 맞는지 규칙으로 정할 수 없다
	- 둘이 같으면 묻지 않는다
- 앱이 화면 앞에 없으면 효과음과 배경음을 내지 않게 했다. 폰에서 최근 앱 화면으로 가도 소리가 안 나는 것을 봤다
- 도안 e179에서 폰으로 보면 구분이 안 되던 연한 흰색 하나를 도안 관리 도구로 합쳤다
- 플레이 데이터 보안 양식을 채웠다. Claude가 개인정보처리방침과 대조해 앱과 어긋난 두 조항을 찾았고, 로그스톤 샵을 맡은 Claude가 고쳐 올렸다
	- 광고 한도는 일부 보상에만 있다는 것, 구글 저장은 플레이 게임즈에 로그인돼 있으면 켤 때 자동으로 된다는 것
	- 이유: 심사가 양식과 방침을 대조한다. 방침이 라이브에 뜬 것을 보고 프로덕션 판을 올리기로 했다
- 레일 보석 겹침은 지금 방향대로 가기로 했다
- 비공개 테스트에 0.1.0+9를 올렸고 검토를 통과했다
- 벨트 아래 단 보석이 빠지면 위에 쌓인 보석이 내려앉게 했다
	- 내려앉을 때와 힌트 보석이 떠오를 때 처음엔 빠르고 끝에서 느려지게 했다
- 가로 판에서 아이템 버튼을 오른쪽 칸 아래 양 구석으로 벌리고, 그만큼 도넛 레일을 키웠다
	- 구석으로 벌린 쪽이 오히려 레일이 작아지는 화면에서는 예전처럼 아래 한 줄로 둔다
- 폰 가로 홈에서 도안 칸을 1.2배로 키웠다. 태블릿은 그대로다
- 글자 스타일 열한 벌, 이름 붙인 색, 모서리·여백·시간 상수를 한자리에 모았다
- 판을 베이크하게 했다(bake, 매 프레임 칸마다 다시 그리는 대신 미리 그려 둔 이미지 한 장을 붙이는 것)
	- Claude가 같은 조건으로 앞뒤를 재니 발열 단계(안드로이드가 알려 주는 기기 열 상태, 0이 평상시)가 끝까지 0이었다(베이크 전은 4분째 1)
- 0.1.0+11 프로덕션 판을 만들어 올리고 있다. 출시 노트 한/영을 업데이트 내역 파일에 정본으로 적었다
- 데스크톱 이사 뒤 도안 원본 자리를 저장소 안으로 옮기고, 도안 관리 도구 포트를 다른 앱과 겹치지 않게 바꿨다

## 막힌 부분

- 플레이에서 받은 폰에 USB로 새 판을 깔려니 거절됐다
	- 원인: 플레이 판은 앱 서명 키로, USB 판은 업로드 키로 서명돼 서로 덮을 수 없다
	- 해결: 구글 저장이 올라간 것을 확인하고 지운 뒤 깔았다. 진행은 저장본에서 돌아왔다
- 프로덕션 판을 올리려니 버전 코드 10을 이미 쓴 번호라고 했다
	- 원인: 오후에 만든 +10 중 하나가 콘솔에 올라가 있었던 것으로 본다
	- 해결: 같은 내용을 +11로 다시 만들었다
- 보석이 내려앉는 것이 덜컹하고 빠지는 느낌이었다. 힌트 누를 때 레일 위 보석도 그랬다
	- 원인: 한 칸 아래로 한 번에 옮겨 그려서 순간이동처럼 보였다
	- 해결: 0.18초 동안 미끄러져 내려가게 했다. 힌트 보석은 0.15초 동안 떠오르며 커진다
- 이사 뒤 윈도우 판 빌드가 링크 단계에서 실패했다
	- 원인: 빌드 도구(MSVC) 두 벌이 깔려 있어 옛 쪽을 집었다
	- 해결: Claude가 새 쪽을 쓰도록 지정하니 통과했다
- 도안 관리 도구가 포트를 비켜 열렸을 때 저장이 거절됐다
	- 해결: 저장 요청의 출처를 실제로 연 포트로 확인하게 고쳤다

### 로그인은 되는데 저장이 안 됐다

폰과 태블릿 둘 다 같은 계정으로 로그인됐다고 뜨는데 진행이 달랐고, 저장된 게임을 켜 둬도 아무것도 안 올라갔다. Claude가 폰 로그를 보고 앱 ID를 의심했고, 콘솔 화면을 찍어 넘기니 앱이 플레이 게임즈에 자기를 소개할 때 쓰는 앱 ID가 Firebase 프로젝트 번호였다. 두 번호 다 열두 자리 숫자라 눈으로는 틀린 줄 모른다. 로그인은 계정만 확인하면 되니 통과하고, 저장은 앱이 맞는지까지 보니 막힌다.

- 해결: 플레이 콘솔의 게임즈 화면에 적힌 번호로 바꿨다. 업로드 키·앱 서명 키·디버그 키 세 지문이 콘솔에 다 등록돼 있는지도 같이 봤다

### 베이크한 효과는 눈으로는 안 보였다

베이크를 넣고 폰으로 해 보니 무엇이 달라졌는지 구분하기 어려웠다. 그래서 Claude가 USB를 뽑은 폰에 큰 도안을 켜 두고 20초마다 전류와 온도를 적어 앞뒤를 쟀다. 두 번째 측정이 8.4분에서 끝나 둘 다 처음 기록 26개(약 8.4분)로 맞췄다.

| | 베이크 전 | 베이크 후 |
|---|---|---|
| 전류 중앙값 | 1171mA | 1018mA |
| 표면 온도 상승 | +3.3°C | +2.4°C |
| 배터리 온도 상승 | +2.2°C | +0.4°C |
| 발열 단계 | 4분째 1 | 끝까지 0 |

- 남은 한계: 한 번씩만 쟀고 베이크 후가 조금 더 식은 상태에서 시작했다. 「나빠지지 않았고 열은 덜 나는 쪽」까지만 말할 수 있다
- 벨트만 돌 때 덜 그리기는 하지 않는다. 지금 그리는 엔진은 매 프레임 전부 다시 그려서 아낄 몫이 없다
