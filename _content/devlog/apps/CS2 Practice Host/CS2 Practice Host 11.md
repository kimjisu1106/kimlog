## 오늘 한 일

- 다음에 할 일 중 혼자 끝나는 것은 Claude에게 정리해 두라고 했다
	- 로그스톤 샵 제품 페이지에 1.3.0부터 1.4.3까지 다섯 판이 다 실려 있었다
- 창작마당 맵 바꾸기 뒤 목소리 끊김이 CS2 쪽에서 고쳐진 것 같다
	- Claude가 Valve 이슈(#3980)를 다시 보니, 10월 28일 CS2 업데이트 뒤로 창작마당 맵끼리 바꿔도 목소리가 남는다는 확인 댓글이 둘 붙어 있었다. 이슈는 아직 열려 있다
	- 앱은 켤 때마다 사이트 안내문으로 「친구는 CS2를 껐다 켜고 같은 링크로」를 띄운다. 고쳐졌는데 두면 없는 버그를 계속 알린다
	- 남의 서버에서 나온 보고라 우리 방장 방에서도 같은지는 모른다. 게임 PC 둘로 직접 들어 보고 들리면 끄기로 했다. 끄는 건 안내문 날짜 한 줄이라 앱을 새로 낼 필요는 없다
	- 직접 들어 보니 고쳐져 있었다. 맵을 바꿔도 목소리가 잘 들렸다
	- Claude에게 안내를 끄라고 했다. 앱 안내문을 끄고 설명서 한·영과 README의 같은 안내도 걷었다
- 라운드 끝 승리·패배 음악이 두 번씩 들리던 것도 해결된 것 같다. 들어 보니 한 번만 들렸다
- 코드 서명 인증서는 수익이 난 뒤 다시 보기로 했다
	- 받거나 켤 때 Windows와 Edge가 띄우는 경고를 없애는 인증서다. 한 장으로 윈도우 앱 셋(CS2 Practice Host·소리꽃·룸톤)을 다 서명할 수 있어서 셋을 묶어 볼 일이었다
	- 다시 볼 때는 윈도우 앱이 몇 번 받혔는지가 아니라, 모바일 앱을 포함해 만든 것 중 어디서든 수익이 나기 시작했는지로 본다
	- 그때까지는 설명서의 「받을 때 경고가 뜨면」 안내로 둔다

- 광고를 붙이고 2주 뒤 노출 수를 보고 계속 둘지 정한다
