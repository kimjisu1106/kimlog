## 오늘 한 일

- 모드를 셋 늘렸다 — 경쟁, 윙맨, 러시
	- 프리미어도 하고 싶었는데 못 넣었다. 밸브 매치메이킹 전용이라 내 게임으로 열 수가 없다. 이름을 댄 넷 중 되는 셋만 들어갔다
	- 윙맨은 쓰는 맵이 다르다. 게임을 켜서 모드별 맵 목록을 읽어 줬다 — 윙맨 일곱 개, 경쟁 열다섯 개. 한국어 이름까지 같이 넘겼다
	- 러시는 봇을 게임이 정한다. 고를 수 있는데 안 먹히는 칸이 제일 나쁘니 봇 칸을 잠갔다. 탈환이 이미 그렇게 되어 있어서 같은 꼴로 맞췄다
- 받아 둔 창작마당 맵을 맵 목록에 띄웠다
	- 이유: 창작마당 맵으로 놀 때도 맵을 바꿀 길이 있어야 한다. 방장이 받아 둔 목록이 그대로 뜨면 고르기만 하면 된다
	- 맵 이름만으로는 뭐가 뭔지 알아볼 수 없어서 Steam에 제목을 물어 와 보여 주기로 했다
- 창작마당 맵을 모드별로 갈랐다 — 제작자가 단 태그를 Steam에 물어서, 윙맨용 맵은 윙맨에만 뜨게
	- 이유: 모드와 안 맞는 맵은 골라도 제대로 안 돌아간다. 목록에 띄우지 않는 게 안내보다 확실하다
	- 태그를 아예 안 단 연습용 맵은 숨기지 않고 캐주얼·경쟁에 둔다. 받아 둔 게 통째로 사라지는 쪽이 더 나쁘다
- 버전을 1.2.0으로 올렸다

## 막힌 부분

- CS2를 켰다 끄면 켜기 버튼이 다시 활성화되지 않았다
	- 원인: ▶를 누르면 두 번 눌리지 않게 버튼을 잠그는데, 다시 푸는 자리가 「서버가 열렸을 때」와 「4분 지났을 때」뿐이었다. 서버가 열리기 전에 게임을 끄면 4분 동안 아무것도 못 한다
	- 해결: 게임이 떴다가 사라진 것을 보면 바로 풀고 「CS2가 꺼졌어요」를 띄운다. 아예 안 뜬 경우는 90초로 줄였다
- 받아 둔 맵이 넷인데 목록에는 열댓 개가 떴다
	- 원인: 큰 맵은 파일 하나가 아니라 목차 하나와 데이터 여러 개로 쪼개져 저장된다. 그걸 전부 맵으로 셌다
	- 해결: 파일을 세지 않고 구독 번호 폴더를 센다. 폴더 하나가 맵 하나다
- 맵 제목이 길면 목록 칸을 넘어갔다
	- 해결: 일정 길이에서 자르고 뒤에 말줄임을 붙인다

### 창작마당 맵을 여는 명령을 세 번 틀렸다

창작마당 맵을 고르고 켜면 게임이 맵을 안 열고 대기 화면에 섰다. 서버가 없으니 맵 안에서 F10도 먹지 않는다 — 맵을 바꿀 서버가 없어서다. 세 꼴을 시도했고 셋 다 안 됐다.

| 넘긴 것 | 결과 |
| --- | --- |
| `+map workshop/<번호>/<이름>` | 대기 화면 |
| `+host_workshop_map <번호>` | 대기 화면 |
| `+map_workshop <번호> <이름>` | 서버는 열렸다. F10도 먹었다. 그런데 「필요한 맵이 클라이언트에 없습니다」가 뜬다 |

앞 둘은 애초에 다른 용도의 명령이었다. 하나는 예전 버전 꼴이고, 하나는 전용 서버를 띄울 때 쓰는 것이라 내 게임으로 여는 쪽에는 안 맞는다. 셋째가 맞는 명령이었고 서버까지 열렸는데, 그 이름의 맵이 없다고 끊겼다.

- 남은 한계: 넘기는 맵 이름이 틀렸다는 것까지만 알아냈다.
